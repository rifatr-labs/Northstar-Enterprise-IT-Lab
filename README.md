# Northstar Enterprise IT Lab

## Enterprise Infrastructure & IT Operations Proof of Concept

Welcome to the Northstar Enterprise IT Lab.

This project simulates the planning, deployment, and operation of a modern enterprise IT environment using industry-standard technologies and documentation practices.

### Project Goals

- Build an enterprise Active Directory environment
- Implement Role-Based Access Control (RBAC)
- Deploy a Knowledge Base
- Deploy a Help Desk ticketing system
- Integrate with Microsoft Entra ID
- Demonstrate automation using PowerShell
- Document the project from planning through implementation
