# 1. Executive Summary

The Northstar Enterprise IT Lab is a fictional enterprise environment designed to simulate the planning, deployment, and operation of a modern corporate IT infrastructure.

The purpose of this project is to demonstrate practical systems administration, identity and access management, IT operations, documentation, automation, and hybrid cloud skills using technologies commonly found in enterprise environments.

Rather than focusing on individual technologies, this project emphasizes the complete lifecycle of an IT implementation—from planning and architecture through deployment, testing, documentation, and operational support.

---

# 2. Business Background

Northstar Solutions is a fictional company with approximately 150 employees across multiple departments.

The organization is modernizing its IT environment to improve security, standardize operational processes, centralize identity management, and establish an internal IT support organization.

The modernization initiative focuses on implementing enterprise technologies while remaining cost-conscious and following industry best practices.

---

# 3. Project Purpose

The purpose of this project is to build a realistic enterprise IT environment that demonstrates the knowledge and skills expected of modern IT professionals.

The project also serves as a long-term technical portfolio documenting design decisions, implementation procedures, testing, troubleshooting, and operational documentation.

---

# 4. Objectives

The primary objectives of this project are:

* Design an enterprise Active Directory environment.
* Implement Role-Based Access Control (RBAC) using security groups.
* Deploy enterprise file services.
* Configure Group Policy to manage client systems.
* Deploy an internal knowledge base.
* Implement a help desk ticketing platform.
* Integrate with Microsoft Entra ID using hybrid identity.
* Demonstrate PowerShell automation.
* Develop enterprise-quality technical documentation.
* Build a professional GitHub portfolio that documents the entire implementation process.

---

# 5. Project Scope

## In Scope

* Active Directory Domain Services
* DNS
* Organizational Units
* User and Group Management
* RBAC
* Group Policy
* Windows File Services
* BookStack Knowledge Base
* Zammad Ticketing System
* Microsoft Entra ID
* Microsoft Entra Cloud Sync
* Azure Arc (where practical)
* Azure Storage (limited use)
* PowerShell automation
* Enterprise documentation
* Testing and validation

## Out of Scope

The following items may be explored in future versions but are not included in Version 1.0:

* Multi-site Active Directory
* Exchange Server
* Microsoft Configuration Manager (ConfigMgr/SCCM)
* Enterprise PKI
* High Availability clusters
* Production disaster recovery
* Large-scale cloud migration

---

# 6. Success Criteria

The project will be considered successful when:

* All core infrastructure components are operational.
* Identity and access are managed through RBAC principles.
* Documentation accurately reflects the implemented environment.
* Every completed sprint includes validation and lessons learned.
* GitHub contains a complete implementation history.
* The repository demonstrates technical and professional communication skills suitable for prospective employers.

---

# 7. Guiding Principles

The project will follow these principles throughout its lifecycle:

* Security by Design
* Least Privilege
* Documentation First
* Infrastructure as Code where appropriate
* Repeatable Implementation
* Continuous Improvement
* Business-Driven Decisions

# 9. Definition of Done

A feature is considered complete only when:

* It has been implemented.
* It has been tested successfully.
* Negative testing has been completed where appropriate.
* Documentation has been updated.
* Screenshots have been captured.
* Lessons learned have been recorded.
* Changes have been committed to GitHub.

---

# 10. Project Vision

The Northstar Enterprise IT Lab is intended to become a continuously evolving demonstration of enterprise IT administration. By documenting not only successful implementations but also design decisions, troubleshooting, testing, and operational procedures, the project aims to reflect the standards and practices used by professional IT teams.
